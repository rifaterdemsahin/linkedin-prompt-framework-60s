# LinkedIn 60s — Prompt Framework (Role · Context · Constraints · Task)

Production pack for a 60-second LinkedIn talking-head: green-screen A-roll, teleprompter, preproduction plan, sanity check, and a shoot → edit → upload checklist.

**Live:** https://rifaterdemsahin.github.io/linkedin-prompt-framework-60s/

## Use on set

1. Open the live page on the iPad under the lens.
2. Tap **Open Prompter**.
3. Space = play/pause. `M` = mirror. `+` / `-` = speed.
4. Shoot three full takes against the green screen.
5. Key over the navy LinkedIn plates in `assets/`.
